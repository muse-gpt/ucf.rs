# geometry.types

几何值类型：二维点、尺寸、矩形、颜色、仿射变换、路径插值与相机。

只放**数据与纯函数**，不做光栅化、不碰帧缓冲、不依赖任何具体设备。上层 `media.*` 与下游产品共用这一套坐标与变换语义。

## 模块

| 模块 | 内容 |
|------|------|
| `geom` | `Vec2` / `Size` / `Rect`、插值、距离 |
| `color` | `Rgba`、`#rgb` / `#rrggbb` / `#rrggbbaa` 解析 |
| `transform` | `Affine2`（平移/缩放/旋转/求逆）与 `Camera` 视图 |
| `path` | Catmull-Rom 平滑、质心、点在多边形内 |

## 边界

- 像素坐标与归一化坐标的**约定**在这里定义，真正采样仍在渲染层。
- 不引入第三方几何/数学库；本 crate 只依赖标准库。
